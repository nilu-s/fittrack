# Cronicl UI Direction

## Leitidee

Ein gedämpft helles Product UI mit klar getrennten Arbeitsbereichen: ruhig,
präzise und persönlich, ohne wie ein Health-Dashboard oder eine Ansammlung
gleichwertiger Karten zu wirken.

## Visuelles System

- **Flächen:** warmer, entsättigter Grund; hellere Inhaltsflächen und eine
  klar erkennbare, aber zurückhaltende Ebene für hervorgehobene Bereiche.
  Reines Weiß ist keine Standardfläche.
- **Trennung:** Section-Header, feine Grenzen und Flächenwechsel definieren
  Bereiche. Schatten dienen nur Dialogen und Sheets.
- **Typografie:** Werte und die nächste Handlung sind zuerst lesbar;
  unterstützende Daten treten optisch zurück.
- **Farbe:** eine Hauptakzentfarbe für Interaktion; Status- und Datenfarben
  ergänzen Text, Icons oder Labels, ersetzen diese aber nie.
- **Dichte:** Listen dürfen kompakt sein. Feature-reiche Mahlzeit- und
  Trainingsinhalte erhalten beim Öffnen ausreichend Raum.

## Nicht Bestandteil der Richtung

- kein weißes, klinisches Interface;
- keine Card-Suppe, keine dekorativen KPI-Grid-Dashboards;
- keine Gradients, Glow oder Glassmorphism;
- keine medizinischen Urteile oder alarmisierende Farbdramaturgie aus
  gewöhnlichen Messwerten.

## Umsetzungskonsequenz

Neue Oberflächen verwenden semantische Tokens und die gemeinsamen Primitives.
Eine visuelle Richtung wird zuerst an der Tagesansicht validiert; Woche und
Settings folgen erst danach.
